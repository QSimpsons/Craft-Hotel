============================================================
  MALLORCA FPS - INSTALLATIE
============================================================

INHOUD
  mallorca-fps/
  ├── fxmanifest.lua
  ├── config.lua
  ├── INSTALL.txt
  ├── client.lua
  ├── server.lua
  ├── sql/install.sql          <-- database
  └── html/ (UI + logo)

STAP 1 - RESOURCE
  Zet de map "mallorca-fps" in je server resources folder.
  Voorbeeld: resources/[local]/mallorca-fps

STAP 2 - SQL (eenmalig)
  Open HeidiSQL / phpMyAdmin en voer uit:

    sql/install.sql

  Dat maakt de tabel mallorca_fps_settings aan.
  (De resource maakt de tabel ook zelf aan bij start, als oxmysql draait.)

STAP 3 - SERVER.CFG
  Zorg dat oxmysql (of mysql-async) al draait, daarna:

    ensure oxmysql
    ensure mallorca-fps

STAP 4 - TESTEN
  1. Join de server
  2. Typ /fps of /fpspanel
  3. Zet een instelling aan (bijv. LAAG of SCHADUWEN UIT)
  4. Reconnect: de instelling moet nog aan staan

CONFIG
  Zie config.lua
  - Config.UseDatabase = true/false
  - Config.Identifier = 'esx' of 'license'
